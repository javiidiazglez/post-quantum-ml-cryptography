## 🔐 Algoritmos Post-Cuánticos Implementados

Este repositorio utiliza **LibOQS** para implementar los estándares post-cuánticos del NIST:

* **ML-DSA** (*Module-Lattice Digital Signature Algorithm*, antes conocido como CRYSTALS-Dilithium) → **Para Firmas Digitales**.
* **ML-KEM** (*Module-Lattice Key-Encapsulation Mechanism*, antes conocido como CRYSTALS-Kyber) → **Para Intercambio de Claves**.
